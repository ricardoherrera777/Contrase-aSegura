# Programa de contraseña segura

Generador y verificador de contraseñas. HTML + CSS + JavaScript puro, sin dependencias ni backend.

## Abrir en VS Code
1. `Archivo > Abrir carpeta...` y elige esta carpeta.
2. Instala la extensión **Live Server** y haz clic en "Go Live", o abre `index.html` directo en el navegador.

## Archivos
- `index.html`: estructura
- `style.css`: estilo terminal/hacker
- `script.js`: generador (crypto.getRandomValues), verificador y conversor de palabras
